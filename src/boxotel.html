Site du Boxotel

Design et intégration web

Voir le projet Voir sur GitHub

Processus

Contexte

Ce projet a été concus dans le contexte d’un cours de design d’expérience ainsi que de conception web. Le but était de faire une refonte du site de Boxotel tout en gardant son contenu principal. Une fois le design complété, il a fallu faire l’intégration en HTML, CSS et Javascript.

Rôles et crédits

Le design complet, l’interactivité ainsi que la programmation a été créée par moi. Toutes images utilisées dans ce projet appartiennent à Boxotel.

Aucune intelligence artificielle n’a été utilisée pour ce projet.

Logiciels et languages

1.

Analyse et comparables

La première étape de ce projet a été d’analyser la version du site de 2020 ainsi que de 2023 afin de bien analyser la marque de la compagnie. Par la suite j’ai collecté des comparables de d’autres sites d’hôtel.

2.

Wireframe et design

Tout en suivant la direction artistique de la compagnie, j'ai créé un tout nouveau wireframe du site de la compagnie Boxotel sur figma. Par la suite, il a suffit de peaufiner le tout afin d'atteindre le design final de la refonte.

3.

Prototypage du design

Une fois le design obtenu, j'ai prototypé le projet afin de pouvoir observer les différentes interactions avec le site et ainsi me préparer à me lancer dans la programmation

4.

Début du HTML et CSS

J'ai commencé à reproduire le design de la refonte créée en créant le code du site en html et css

5.

Ajout de responsive et javascript

Une fois la base du site créée en html css, j'ai pu ajouter du responsive afin de pouvoir voir le site en mobile et j'ai ajouté le javascript utilisé pour diverses fonctions du site.

Médias supplémentaires

Mes apprentissages

Ce projet m’a permis d’expérimenter un style un peu plus moderne et avec une base imposée afin qu’on suive le design de la marque. Il a d’ailleurs aussi été le premier projet que j’ai transféré mon propre design à un site dont j’ai également fait le code .
